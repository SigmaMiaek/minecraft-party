# Minecraft Party 0.6.0 — optional Cloudflare party codes

Adds a deployable Cloudflare Workers Free service with SQLite Durable Objects, six-digit party codes and explicit host approval. Set the same trusted workers.dev URL on both clients in Party → Party codes. There is no preconfigured or deployed central service. Full private mp3/mp2 invitations remain available.

Short codes identify a Party; only the host may authorize releasing its invitation to an individual request capability. Compare the request number with your friend before approval: displayed names are not authenticated. The configured service and Cloudflare are trusted with invitations. Minecraft authentication and pinned Party TLS are preserved after invitation delivery.

Includes expiry, revocation, bounded pending requests and persisted rate limits, plus English/Polish UI. Gameplay still uses e4mc. This does not add invitations through Mojang's friends list.

Deployment and limitations: [Cloudflare setup](https://github.com/SigmaMiaek/minecraft-party/blob/main/docs/CLOUDFLARE.md). New code-based joining has not been tested in two running Minecraft clients or a deployed user account; this is a prototype.
