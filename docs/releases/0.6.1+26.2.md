# Minecraft Party 0.6.1 — six-digit vanilla join screen

Replaces the long invitation field with six compact vanilla digit boxes, grouped 3–3, and a separate Join Party button below them. Typing advances focus, backspace works across boxes, arrows navigate, and a whole code can be pasted (also formatted as 123-456). Join remains disabled until all six slots are filled.

The deployed Cloudflare URL is configured automatically. Missing, empty and invalid old service preferences migrate to the default; existing valid administrator overrides remain. There is no URL entry in the normal Party flow. Hosting from the Party screen uses e4mc.

Removes all long mp2/mp3 input and copy controls from the UI. Copy only returns a ready six-digit code. Long invitation data, the TLS pin and the access secret remain internal: the directory transfers them after explicit host approval. This preserves the connection security and Minecraft authentication. The configured code service remains trusted with invitations.

Includes English/Polish text and input/configuration regression coverage. Real gameplay and visual inspection in two running Minecraft clients remain to be tested. The existing Cloudflare service does not need a protocol or database migration.
