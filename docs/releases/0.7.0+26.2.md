# Minecraft Party 0.7.0 — leadership handoff and private code controls

- The leader can click the star beside a member in the lobby to hand over leadership. The previous leader stays as a member.
- Leave Party selects the next connected member in lobby order and prepares that member's TLS listener and e4mc relay before moving online clients. Party identity, membership, reconnect credentials, chat, member limit and bans are transferred over the existing authenticated channel. If preparation fails, another candidate is tried; the current leader stays when no candidate can take over.
- Codes are hidden by default. The eye reveals/hides them, and the adjacent copy icon works while hidden. A changed code hides itself again. The main lobby no longer leaks the raw code in a management-button label.
- Correct six-digit codes now join without host approval. New rooms explicitly request auto-join from the updated Worker. Anyone who knows or guesses a live code can enter; the code is now the access credential, protected by expiry and online request limits rather than a host decision.

All members must update to 0.7.0 because the TLS lobby wire version changed. Deploy the updated Cloudflare code from main (Git integration should do this automatically). Health now includes `"autoJoin":true`; an outdated service produces an update-required message rather than leaving clients waiting for approval.

Handoff supports a normal Leave Party action while the game remains running. It does not recover from an abrupt process kill, power loss, an unreachable successor, or a failed connection after commit. There can be a short reconnect interval. An old singleplayer world is not transferred: its multiplayer session closes and members return to the lobby. The new leader gets a new invitation code; existing online members move through the authenticated handoff without entering it. Offline members that miss the handoff need the new code. Manual handoff is available in the lobby, and a successor's unrelated active world is never shared automatically.

Local tests cover the migration model, bounded message encoding, credential continuity, ban preservation, code masking and directory auto-join. The actual TLS handoff has a loopback integration test in CI. Running Minecraft instances, the GUI and an internet handoff through e4mc have not been tested by this environment.
