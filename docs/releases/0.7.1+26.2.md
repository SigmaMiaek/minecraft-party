# Minecraft Party 0.7.1 — a Party shortcut for replaced main menus

- Press **P** in the main menu to open Party, even when a compatible Fabric client replaces the vanilla title screen and does not show the Party button.
- Rebind or unbind it in **Options → Controls → Key Binds → Minecraft Party → Open Party (menus)**. Minecraft saves the binding in its normal options; both Polish and English labels are provided.
- The shortcut uses Fabric's screen keyboard events on every initialized screen, instead of relying on a particular main-menu class or an in-world key queue. Back/Escape returns to the original menu instance.
- Active worlds, existing connections, loading overlays, vanilla settings/key rebinding, confirmation/world-selection screens and Party text entry are protected. Focused vanilla text fields, including those inside nested containers, keep their input. Ctrl/Alt/Super combinations are not consumed as ordinary letter shortcuts.

The default P is also Minecraft's in-world social-interactions key. Party only handles menu input and does not replace that in-world action. A different keyboard key can be selected in Controls.

The lobby protocol is unchanged and remains compatible with 0.7.0. Only players who need the shortcut need this update.

Compilation and policy tests run locally and in Windows/Linux Gradle CI. This environment has not run Lunar, Dawn Client, or two Minecraft clients to validate their actual menus. The client must support this Minecraft/Fabric version and load Minecraft Party and Fabric API; the shortcut cannot load the mod into an incompatible client.
