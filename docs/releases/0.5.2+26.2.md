# Minecraft Party 0.5.2 — prototyp, Minecraft 26.2

Lobby Party, prywatne zaproszenia i szyfrowany tunel do świata hosta przez publiczny relay e4mc. Bez własnego hostingu i bez zależności od Essential Mod.

W tym wydaniu:

- Naprawione zatrzymanie odczytu, gdy prefiks routingu przychodzi osobno od TLS ClientHello. Mogło powodować timeout przy dołączaniu do lobby lub świata.
- Automatyczne dołączanie działa także z niestandardowego menu klienta. Aktywna gra, inne połączenie, ładowanie oraz wybór/tworzenie świata są chronione.
- Rozszerzona diagnostyka relaya, udostępniania świata i autodołączania. Komunikat TLS przez relay nie twierdzi, że potwierdzono dotarcie do hosta.

Instalacja: Minecraft Java 26.2, Java 25, Fabric Loader 0.19.3+ i Fabric API 0.161.0+26.2. Zastąp poprzedni JAR w `mods` na obu komputerach, uruchom grę ponownie i utwórz nowe Party w trybie Internet (relay e4mc). Prześlij prywatnie nowe zaproszenie mp3.

Przy pierwszym tworzeniu Party host pobiera bibliotekę sieciową e4mc z przypiętym SHA-256. Publiczny relay jest zewnętrzną zależnością; nie ma gwarancji dostępności. Lunar nie został tutaj przetestowany. Testy automatyczne nie potwierdzają pełnej rozgrywki na dwóch komputerach.

Zgłoszenie problemu z pobieraniem użytkownik wyjaśnił jako dotyczące Opery GX i podał brak wykryć w VirusTotal. Nie wykonywano tu niezależnego skanu. Szczegóły biblioteki sieciowej i zgłoszenia: `docs/ANTIVIRUS.md`.
