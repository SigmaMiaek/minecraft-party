# Minecraft Party 0.9.0 — menu i dziesięć miejsc

Minecraft Java 26.2, Java 25, Fabric Loader 0.19.3+, Fabric API 0.161.0+26.2. Usuń poprzedni JAR Party i zaktualizuj wszystkich uczestników. Utwórz nowe Party po ponownym uruchomieniu gry.

- U góry po lewej: nazwa lobby, natywny suwak 2–10 graczy oraz tworzenie Party z wyborem Prywatne / Publiczne. Nowe lobby domyślnie jest prywatne.
- Poniżej: sześć pól kodu i Dołącz. Działa wpisywanie i wklejanie całego kodu.
- Po prawej: rzeczywista lista publicznych lobby z miejscami, statusem, stronicowaniem i Dołącz. Odświeża się co 15 sekund bez przejmowania fokusu formularza. Pełne lobby ma nieaktywny przycisk.
- Małe okna mają zakładki Utwórz / Dołącz kodem / Publiczne. Tło dirta i kontrolki Minecrafta pozostają spójne z vanilla. Dostępne są polskie i angielskie etykiety.

Limit obejmuje hosta. Most świata ustawia wybrany limit na zintegrowanym serwerze wyłącznie podczas publikowania świata przez Party. Po wyjściu, anulowaniu lub błędzie przywraca normalny limit. Nie zmienia banów, whitelisty, uprawnień ani uwierzytelniania Minecrafta. Zewnętrzny serwer multiplayer nadal ma własne zasady i liczbę miejsc.

Protokół MPT5 pozwala przesyłać stan dziesięciu uczestników. Nie jest zgodny z MPT4 w modzie 0.8.0. Wdróż aktualny katalog `cloudflare` z main w istniejącym Workerze; adres konfiguruje się automatycznie. Usługa nadal obsługuje publiczne lobby 0.8.0, ale każda wersja widzi listę wyłącznie swojego protokołu. Prywatne pokoje nie pojawiają się na żadnej liście.

Sprawdzenia lokalne: kompilacja javac 25 względem rzeczywistego JAR Minecrafta 26.2 i Fabric API, 94 testy bez gniazd sieciowych, 23 przypadki polityki katalogu i statyczna weryfikacja artefaktu oraz sygnatur Mixina. Lokalny Gradle nie uruchamia się z powodu blokady gniazd w środowisku. Publikacja JAR wymaga przejścia pełnych zadań Gradle Windows/Linux, testów tunelu TLS na loopback oraz testu Worker/SQLite w GitHub Actions.

Nie wykonano tu renderowania menu w uruchomionej grze ani testu dziesięciu zalogowanych klientów. Rozgrywka na dwóch komputerach, Lunar/Dawn, publiczny relay, LAN i różne sieci NAT wymagają weryfikacji w grze. Nazwy i liczby graczy w katalogu są deklaracją hosta. Prywatny kod nadal jest uprawnieniem do dołączenia; przechowuj go prywatnie.
