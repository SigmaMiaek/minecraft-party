# Minecraft Party 0.11.1 — ikona Party w menu głównym

Przycisk **Party** znajduje się teraz w rzędzie małych ikon menu głównego, po prawej stronie ostatniej sąsiedniej ikony. Ma rozmiar 20×20, standardowe tło przycisku Minecrafta i pikselową ikonę trzech graczy z zieloną postacią pośrodku. Po najechaniu pokazuje **Otwórz Party** lub **Open Party**; działa również nawigacja klawiaturą i narrator.

Pozycja wynika z rzeczywistych przycisków języka i dostępności. Uwzględnia sąsiednie ikony dodane później przez inne mody, np. Mod Menu, oraz przebudowanie menu po zmianie rozmiaru okna i skali GUI. Przy braku miejsca po prawej używa wolnego miejsca po lewej stronie tego samego rzędu. Jeśli oba miejsca są zajęte, nie zasłania innych przycisków; Party nadal można otworzyć skrótem **P**. Menu ESC zachowuje dotychczasowy przycisk zarządzania Party.

Minecraft **26.2**, Java **25**, Fabric Loader **0.19.3+** i Fabric API. Wydanie zachowuje MPT7 i zgodność sieciową z Party 0.11.0; nie wymaga zmian usługi kodów. Przekazywanie świata pozostaje dostępne.

Walidacja: kompilacja z rzeczywistymi zależnościami Minecraft/Fabric oraz istniejące testy. Publikacja wymaga buildów i testów Windows/Linux oraz kontroli usługi kodów w GitHub Actions. Pełnego uruchomienia menu w kliencie Minecraft z Mod Menu, Lunarem lub Dawn w tej sesji nie wykonano.
