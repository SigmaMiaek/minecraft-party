# Minecraft Party 0.10.0 — Watch Party dla YouTube

Dodaje ekran YouTube w świecie, sterowanie hosta (odtwarzanie, pauza i przewijanie), dołączanie widzów, podgląd w menu i indywidualną głośność cichnącą z odległością. Nowy przycisk: **ESC → Party → Watch Party…**. Host wkleja link, ustawia ekran, a widzowie dołączają i klikają raz podgląd, aby włączyć odtwarzanie i dźwięk.

**Wszyscy potrzebują Party 0.10.0+26.2. Do oglądania wymagany jest dodatkowo [Rinku dla Fabric 26.2](https://modrinth.com/mod/rinku/versions?g=26.2&l=fabric), wersja 3.0.4+ z gałęzi 3.x.** Rinku pobiera własny natywny pakiet przeglądarki. Bez niego pozostają zwykłe funkcje Party. Minecraft 26.2, Java 25 i Fabric API są nadal wymagane.

Protokół MPT6 przenosi stan oglądania przez istniejący kanał TLS. Worker z main obsługuje MPT4/MPT5/MPT6 i pokazuje publiczne lobby wyłącznie zgodnym klientom. Nie trzeba zmieniać adresu usługi. Nowy świat usuwa ekran poprzedniego świata; wyjście czy utrata połączenia sprząta lokalny odtwarzacz.

Jest to prototyp YouTube, **bez Netflixa i Prime Video**. Prywatne filmy, ograniczenia osadzania i regionu nadal obowiązują. Film każdy pobiera bezpośrednio z YouTube, a nie od hosta. Sieć, buforowanie i reklamy mogą wpływać na zgodność czasu; nie obiecujemy synchronizacji klatka w klatkę.

Weryfikacja lokalna: kompilacja javac 25 z rzeczywistym Minecraft 26.2/Fabric API, 99 testów bez gniazd sieciowych i kontrola artefaktu. Publikacja wymaga pełnego Gradle Windows/Linux, testów TLS i lokalnej strony HTTP, testów poleceń odtwarzacza oraz sprawdzenia publicznego JAR-a Rinku i wdrożonej usługi kodów w CI. Nie uruchomiono tu Minecrafta z filmem, GPU ani dwoma zalogowanymi klientami.
