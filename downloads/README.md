# Gotowe prototypy moda

[Pobierz Minecraft Party 0.6.1 — sześć pól kodu i automatyczny adres usługi](https://github.com/SigmaMiaek/minecraft-party/raw/refs/heads/main/downloads/minecraft-party-0.6.1%2B26.2.jar)

Wersja 0.6.1 jest lokalnym buildem JDK 25, z 77 zaliczonymi testami bez gniazd. Nie jest artefaktem ukończonego builda Gradle Windows. Kompilacja lokalnego Gradle jest blokowana ograniczeniem interfejsów sieciowych środowiska. Testy CI nowej wersji sprawdź w [Actions](https://github.com/SigmaMiaek/minecraft-party/actions). Nie potwierdzono tu wizualnie ekranu w działającej grze ani dołączania przez kod na dwóch klientach Minecraft.

Zamień JAR moda na obu komputerach i uruchom grę ponownie. Wymagania: Minecraft 26.2, Java 25, Fabric Loader 0.19.3+, Fabric API 0.161.0+26.2. Adres usługi jest ustawiany automatycznie; nie trzeba wpisywać URL-a. Dołącza się wyłącznie przez sześć cyfr i zatwierdzenie prośby przez hosta. Nie trzeba ponownie wdrażać Cloudflare.

Sumy plików w tym katalogu są w [SHA256SUMS](SHA256SUMS). Wydania Gradle w Releases są osobnymi artefaktami i mają własne sumy. Publikacja JAR-a nie zastępuje skanu antywirusowego; nie wykonano tu skanu Defenderem.

Starsze wersje 0.6.0 i 0.5.2 pozostają dostępne jako pliki w tym katalogu.
