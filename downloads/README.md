# Gotowy mod 0.5.2

[Pobierz minecraft-party-0.5.2+26.2.jar](https://github.com/SigmaMiaek/minecraft-party/raw/refs/heads/main/downloads/minecraft-party-0.5.2%2B26.2.jar)

Minecraft 26.2, Java 25, Fabric Loader 0.19.3+ i Fabric API 0.161.0+26.2. Skopiuj JAR do `mods`; usuń wcześniejszy Minecraft Party i uruchom grę ponownie.

To identyczna kopia lokalnego artefaktu, skompilowanego JDK 25 z 65 zaliczonymi testami bez gniazd. Suma jest w [SHA256SUMS](SHA256SUMS). Źródła są w tym repozytorium. Publikacja na GitHub nie zastępuje analizy antywirusowej.

Wydania w sekcji Releases są budowane oddzielnie przez Gradle w GitHub Actions po przejściu testów Windows/Linux i mają własny plik SHA256SUMS.
